## Detected ambiguity

The only material phase ambiguity is confirmation in Definition 2 versus Algorithm 2: confirmation evidence is part of the abstract eligibility predicate, but the executable algorithm reserves before obtaining confirmation. The implementation conservatively separates `precheck_eligible` from `confirmation_ok`, never injects without both, and records the distinction in decisions and tests. A second, now-resolved tension was the timing of the budget decrement: the original Algorithm 2 decremented `u` at finalization while the lifecycle section decremented it at reservation. Decision D4 fixes the decrement at reservation, the paper's Algorithm 2 was synchronized, and the reference store decrements a mutable remaining counter while keeping the authenticated metadata immutable. No theorem/algorithm contradiction requires changing a claimed result.
