\section{Conclusion}
\label{sec:conclusion}

\SH{} reframes how mobile AI agents handle credentials: by minting unforgeable, destination- and task-bound handles at authoritative OS sources and enforcing atomic zero-exposure resolution into verified UI fields, secrets never enter agent perception, resist prompt injection, and remain replay-immune. Empirical evaluation on Android~14 across 10 benchmarks confirms \SH{} eliminates secret exposure ($0/30$) and redirection ($0/30$ vs.\ $30/30$) with negligible overhead ($5.42\,\mu\text{s}$ vault mint, $4.2\,\text{ms}$ end-to-end) and zero task regression ($\Delta = 0.00$), establishing a principled OS-level foundation for mobile AI security.
