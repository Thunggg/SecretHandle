\section{Artifact Appendix}
\label{sec:artifact}

\paragraph{Scope.} The artifact is a Python reference model and synthetic evaluation harness for \SH. It validates the algorithms, state-machine semantics, resolver policy, redaction, metrics, and provenance end-to-end on synthetic canaries. It is \emph{not} an AOSP security boundary and does not by itself establish the Android, StrongBox, WebView, screenshot, accessibility, or private-input claims; those require the pinned AOSP build and device described in the evaluation plan (Section~\ref{sec:evidence}). Every generated output is labeled \texttt{synthetic smoke-test output, not a paper result}.

\paragraph{Contents.} The artifact ships the reference package (\texttt{src/secrethandle}), typed external-adapter contracts, synthetic and template configurations, plotting and experiment entry points, the offline pytest suite, paper-to-code traceability and math audits, and the canary-isolation smoke check. It contains no real credential, payment instrument, or production OTP; all canaries are randomly generated per run.

\paragraph{One-command build and run.} From the artifact root, with Python 3.10+ (3.11+ recommended):
\begin{verbatim}
python -m venv .venv && source .venv/bin/activate
python -m pip install -e '.[dev]'
make check
\end{verbatim}
\texttt{make check} is the single entry point; it runs lint (\texttt{ruff}), type-check (\texttt{mypy}), the offline pytest suite, and the canary smoke check in order and fails on the first error. On Windows, override the interpreter, e.g.\ \texttt{make check PYTHON=.venv/Scripts/python.exe}. The demo, plots, and killer-stage runner are available as \texttt{make demo}, \texttt{make plots}, and \texttt{make killer}.

\paragraph{Offline synthetic-canary smoke test.} \texttt{make smoke} runs \texttt{scripts/smoke\_check.py}. It executes the deterministic synthetic pipeline from a pinned configuration, reconstructs every canary the run could have minted, scans all generated artifacts for those canaries, and asserts the provenance flags (\texttt{real\_experiment=false}, \texttt{paper\_placeholder\_numbers\_used=false}, and the synthetic label). It exits non-zero on any leak or provenance violation. The check is fully offline: it uses no network, dataset, model, GPU, Android device, or credential. A reference run (seed \texttt{20261017}, $6400$ trials over eight attack families, $1599$ reconstructed canaries) completed with zero leaks and correct provenance.

\paragraph{Reproducing the reported simulation numbers.} The preliminary-evidence numbers in Section~\ref{sec:evidence} are regenerated by \texttt{make evidence} (equivalently, the following command, wrapped here for width):
\begin{verbatim}
python scripts/run_experiment.py \
  --config configs/preliminary_evidence.yaml \
  --stage killer
\end{verbatim}
The run records the seed, platform, Python version, and a SHA-256 configuration digest in \texttt{provenance.json}; per-trial outcomes are written to \texttt{trials.jsonl} without ever storing a canary value. These are simulation outputs, not device measurements.

\paragraph{Device-tier reproducibility.} In addition to the offline Python reference model, the artifact includes the on-device prototype under \texttt{device/b3-secrethandle/}, comprising the Android Accessibility overlay service, the vault resolver, the microbenchmark suite (\texttt{BenchmarkRunner.java}), and the automated benchmark driver scripts for AndroidWorld. These components can be deployed and evaluated on any Android~14+ emulator image or physical userdebug device with Accessibility privileges.

\paragraph{Integrity and license.} Configuration files are hashed at load time, and keys whose names resemble secrets, credentials, passwords, tokens, or API keys are redacted from provenance. The artifact is released under the Apache License~2.0 with all experiment runners, benchmark logs, and analysis scripts fully reproducible.
